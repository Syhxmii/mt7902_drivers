Panduan Lengkap Perbaikan Wi-Fi & Bluetooth MediaTek MT7902 di Fedora (Kernel 6.17)
Bagian 1: Masuk ke Kernel Lama & Hapus Kernel 7.0

Karena kernel 7.0 bermasalah, kita harus kembali ke kernel 6.17 yang stabil dan menghapus kernel yang rusak.

    Booting ke Kernel 6.17:

        Matikan laptop secara paksa (tahan tombol power).

        Nyalakan kembali. Begitu logo vendor (Asus/Acer/Lenovo/dll) hilang, tekan tombol Esc atau Shift berulang kali untuk memunculkan menu GRUB Bootloader.

        Gunakan panah bawah, pilih Fedora Workstation ... 6.17..., lalu tekan Enter.

    Hapus Kernel 7.0 yang Bermasalah:
    Setelah masuk ke desktop, buka Terminal dan jalankan perintah berikut untuk mengecek versi persis kernel 7.0 Anda:
    Bash

    rpm -q kernel

    Hapus kernel 7.0 tersebut (ganti 7.0.x-xxx sesuai dengan versi yang muncul di terminal Anda, misal: 7.0.1-200.fc43):
    Bash

    sudo dnf remove kernel-core-7.0.x-xxx

Bagian 2: Persiapan Koneksi & Alat Tempur

Chipset MT7902 membutuhkan driver eksternal (out-of-tree driver). Karena Wi-Fi mati, sambungkan HP Android/iPhone Anda ke laptop menggunakan kabel data, lalu aktifkan fitur USB Tethering agar laptop mendapatkan internet sementara.

Setelah terhubung ke internet, jalankan perintah di bawah ini secara berurutan:

    Install Alat Kompilasi (Development Tools):
    Bash

    sudo dnf install git build-essential kernel-devel-$(uname -r) kernel-headers-$(uname -r) elfutils-libelf-devel zstd

    Unduh Source Code Driver MT7902:
    Bash

    git clone --depth 1 https://github.com/OnlineLearningTutorials/mt7902_temp
    cd mt7902_temp

    Suntik File Header airoha_offload.h yang Hilang:
    Bash

    sudo mkdir -p /usr/src/kernels/$(uname -r)/include/linux/soc/airoha
    sudo curl -sL "https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/plain/include/linux/soc/airoha/airoha_offload.h?h=v6.19" -o /usr/src/kernels/$(uname -r)/include/linux/soc/airoha/airoha_offload.h

Bagian 3: Kompilasi Driver

Sekarang kita akan menjalankan script utama untuk membangun (compile) file driver Wi-Fi dan Bluetooth.

    Jalankan Script Installer:
    Bash

    sudo chmod +x fix_my_wifi.sh
    sudo ./fix_my_wifi.sh

        ⚠️ Catatan: Jika di akhir script muncul error terkait Bluetooth, abaikan saja. Proses compile file utamanya biasanya sudah berhasil selesai di latar belakang.

Bagian 4: Kompresi Modul Driver (.ko ke .ko.zst)

Fedora modern mewajibkan semua modul kernel dikompresi menggunakan format Zstandard (.zst). Mari kita masuk ke folder hasil kompilasi dan mengompresnya.

    Kompres Driver Wi-Fi:
    Bash

    cd ~/mt7902_temp/linux-6.17/drivers/net/wireless/mediatek/mt76/mt7921/
    sudo zstd -f --rm *.ko

    Kompres Driver Bluetooth:
    Bash

    cd ~/mt7902_temp/linux-6.17/drivers/bluetooth/
    sudo zstd -f --rm *.ko

Bagian 5: Penyalinan Modul, Firmware, dan Aktivasi

Langkah terakhir adalah memindahkan file yang sudah siap ke folder sistem Fedora Anda.

    Salin Modul Driver (.ko.zst) ke Sistem:
    Bash

    sudo cp ~/mt7902_temp/linux-6.17/drivers/net/wireless/mediatek/mt76/mt7921/*.ko.zst /lib/modules/$(uname -r)/kernel/drivers/net/wireless/mediatek/mt76/mt7921/

    sudo cp ~/mt7902_temp/linux-6.17/drivers/bluetooth/*.ko.zst /lib/modules/$(uname -r)/kernel/drivers/bluetooth/

    Salin Firmware Modul:
    Bash

    cd ~/mt7902_temp
    sudo cp -r firmware/* /lib/firmware/mediatek/

    (Jika setelah di-ls folder tersebut bernama mt7902_firmware, ganti kata firmware/* menjadi mt7902_firmware/*)

    Perbarui Dependensi Modul & Restart Laptop:
    Bash

    sudo depmod -a
    sudo reboot

Setelah laptop menyala kembali, lepas kabel tethering HP Anda. Wi-Fi dan Bluetooth MediaTek MT7902 seharusnya sudah aktif dan terdeteksi dengan normal di Fedora 43 Anda.
